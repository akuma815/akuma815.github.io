# 언톨드 레전드 v1.0 등록 — 2026-10-31

사용자가 패드 이동 문제를 PPSSPP 설정 문제로 확인하고 v1.0 공식 릴리즈 및 기존 Pages 양식의 등록을 요청했다.

- [공식 릴리즈](https://github.com/akuma815/psp-untold-legends-brotherhood-of-the-blade-kr-patch/releases/tag/v1.0): 원본 ISO를 새 한글 ISO로 만드는 Windows 패치 ZIP과 체크섬 2개. 원본/완성 게임 ISO는 공개하지 않는다.
- [게임별 페이지](https://akuma815.github.io/games/psp-untold-legends-brotherhood-of-the-blade-kr-patch/): 기존 PSP UMD 카드·소개·다운로드·공유·방명록/신고 양식을 사용한다. 기존 23개 항목을 보존하고 24번째 항목을 추가했다. 쉬버스의 작업 중 표시는 유지한다.
- 변경: `data/catalog.json`, `data/catalog.js`, `data/screenshots.json`, 전체 PNG 1개 및 출처/인계 문서. 사이트 기능 코드는 바꾸지 않았다.
- 실제 화면: 동결 current27 폴더 실행의 기존 타이틀 메뉴 전체 PNG를 그대로 복사했다. 해당 게임 80파일은 v1.0 ISO 내용과 같다. ISO 실행 캡처 또는 전체 플레이 증거로 확대하지 않는다. 원본/공개 PNG SHA256 `cb2f28a71880f8911ed14efe5b2123dcf9846ecde13580fff3bc4155ea61d3f2`.
- 문안은 기존 사이트처럼 친근한 반말을 따르며 지원 한국판·번역 범위·원문 유지·저장창 설정·미검증 범위를 적었다. 개인 조작 설정은 올리지 않았다.
- 로컬 정적/DOM 검사 PASS: 24개 게임, 배포 중 23개·작업 중 1개. 기존 공유 브라우저 검사 PASS: 24개 개별 HTTP/공유 메타데이터·데스크톱·모바일·JS 비활성 대체 콘텐츠.
- 명령: `python -X utf8 scripts/update_catalog.py --verify-remote`, `python -X utf8 scripts/check_site.py`, `python -X utf8 scripts/check_sharing_browser.py --channel msedge`. 공개 후 개별 언톨드 페이지의 실제 표시·다운로드 연결·이미지를 다시 확인한다.

배포는 기존 `catalog-pages.yml`의 main 푸시→검사→Pages를 사용한다. 실제 공개 확인은 Actions 성공 및 공개 URL 관찰과 구분해 기록하며, 게임 플레이 검증을 뜻하지 않는다. 배포/원격 다운로드 확인의 원시 기록은 게임 프로젝트 `qa/publication/20261031_v1_0/` 및 사이트 `qa/untold_release_20261031/`에 남긴다.
