## 최신 변경 — 소문자 아이디와 게임방 이름

후속 문구 수정: 친구를 초대하는 히어로 하단 문구에서 아이디 서명을 빼고 **`옆자리 비워 뒀어. 어서 와, 같이 하자!`**로 변경했다. 브라우저 제목·로고의 소문자 아이디는 유지한다.

사용자 지적에 따라 홈페이지 브라우저 제목과 공유 제목을 **`akuma815 — 우리들의 작은 게임방`**으로 바꿨다. 상단 로고·접근성 이름·히어로 서명·푸터·팩 라벨도 소문자 `akuma815`로 통일했다. 푸터의 부제도 `우리들의 작은 게임방`이다. 게임별 제목은 `{게임명} 한글 패치 {버전} | akuma815`로 표시하고, 소개를 닫거나 목록으로 돌아갈 때 새 홈 제목을 복원한다. 개별 HTML의 Open Graph/Twitter 제목과 사이트 이름도 같은 표기다.

기존 정적/DOM 검사와 독립 Edge 로컬 검사를 통과했다. 브라우저 제목·홈 OG 제목·상단/하단 표기·닫은 후 제목 복원·21개 게임의 소문자 공유 제목/사이트 이름을 검사에 포함했다. 공개 배포 후 동일 검사는 `python scripts/check_sharing_browser.py --url https://akuma815.github.io/ --out qa/branding/live`로 실행하고 결과를 그 경로에 기록한다. 게임 데이터와 패치 릴리즈는 변경하지 않았다.

## 게임별 공유 기능

게임별 패치 공유 기능을 추가했다. 사용자가 홈페이지 전체 대신 특정 게임을 공유하고 싶다고 요청했다.

- 게임 소개의 **이 게임 링크 복사**가 `/games/{id}/` 고유 주소를 복사한다. 공유 주소 진입·새로고침은 해당 게임 소개를 바로 열며 목록에서 고르는 기존 팩 삽입 연출은 유지한다.
- 목록에서 소개를 열면 `?game={id}`로 주소를 갱신한다. 뒤로·앞으로 가기와 닫기/Escape도 소개 상태에 반영한다.
- 카탈로그 21개 게임 각각에 대해 정식 URL·게임명·설명·캡처 Open Graph/Twitter 태그를 포함하는 HTML을 Actions에서 생성·게시한다. JavaScript 없이도 개별 다운로드와 안내가 있다.
- 클립보드 거부 시 주소를 선택해 수동 복사를 안내한다. 없는 게임 ID는 전체 목록으로 안내한다.

예: https://akuma815.github.io/games/nes-tom-and-jerry-kr-patch/

주요 변경: `assets/app.js`의 공통 소개 열기 경로, `assets/sharing.js/css`, `index.html`, `scripts/generate_game_pages.py`, 기존 `catalog-pages.yml`의 개별 페이지 생성 단계. 카탈로그와 게임 릴리즈 파일은 변경하지 않았다. 운영·주소 규칙은 [SHARING.md](SHARING.md)를 따른다.

검증 완료: 기존 `check_site.py`의 정적·DOM 검사와 격리 Edge의 로컬/실제 공개 사이트 PC·모바일 검사가 모두 통과했다. 공유 주소 열기, 복사, 새로고침, 뒤로/앞으로, 닫기, 기존 삽입/스킵, 잘못된 ID, 클립보드 실패, 모든 21개 HTML의 HTTP 200·제목·설명·이미지·정식 주소, JavaScript 없는 다운로드를 확인했다. JS 오류는 0이다. 공개 결과는 [SHARING_VERIFICATION_2026-10-17.json](SHARING_VERIFICATION_2026-10-17.json)에 보존했다. PNG·원시 결과는 기존 무시 경로 `qa/sharing/local`, `qa/sharing/live`에 있다. 외부 메신저 발송이나 각 서비스의 실제 미리보기 캐시는 검증하지 않았다.
