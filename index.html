게임 화면도 같이 구경해 봐! 작업할 때 찍은 거라 지금 패치랑 조금 다를 수 있어. 한글 타이틀을 먼저 보여 주고, 그래픽 작업 이미지나 영상 자막이면 따로 적어 둘게.

같이 게임할 준비 됐어?

옛날엔 팩을 쏙 꽂았지?
이번엔 한글 패치를 챙겨 보자!

  1. 01

    먼저, 원본이 맞는지 보자.

    게임마다 맞는 원본이 달라. 저장소에서 지역·리비전·체크섬을 확인해 줘. 네가 준비한 원본은 따로 잘 보관하자.

  2. 02

    이제 한글 패치를 받자!

    ‘패치 받기’를 누르고 GitHub 릴리즈에 첨부된 패치 파일을 받으면 돼. Source code 압축파일은 패치 배포본과 다른 파일이니까 이름을 잘 봐 줘.

  3. 03

    설명 보면서 하나씩 해 보자.

    xdelta·IPS·모드 설치처럼 게임마다 방법이 달라. README에 적힌 순서대로 해 줘. 알려진 제약이랑 예전 세이브를 쓸 수 있는지도 같이 살펴보자.

i

여기는 팬이 만든 비공식 한글 패치를 모아 둔 작은 게임방이야. 원본 ROM·ISO·BIOS나 패치가 끝난 게임 파일은 여기서 나눠 주지 않아. 게임과 상표의 권리는 각각의 권리자에게 있어.
