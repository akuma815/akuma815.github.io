# AKUMA815 한글 패치 아카이브

**사이트: https://akuma815.github.io/**

게임과 독립된 `akuma815/akuma815.github.io` 저장소의 `main` 브랜치 루트에서 게시합니다. [최신 인계](docs/HANDOFF.md)

게임별 한글 패치·최종 릴리즈·적용 안내를 모은 GitHub Pages 정적 사이트입니다.

## 기능

- 한국어·영문 게임명 검색, 플랫폼 필터, 정렬, 배포 중인 패치만 보기
- 게임별 상세 안내와 공개 릴리즈·소스 링크
- 공개 등록 대기와 배포 중 상태 구분
- 모바일 레이아웃, 키보드 탐색, 상세 대화상자

## 로컬 미리보기

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 빌드 및 npm 설치가 필요 없습니다.

## 목록 갱신

`data/catalog.json`이 목록 원장입니다. `data/catalog.js`는 같은 내용을 브라우저에서 읽을 수 있도록 생성한 파일입니다.

```powershell
python scripts/update_catalog.py --verify-remote
```

로그인된 GitHub CLI로 공개 저장소와 릴리즈 첨부 존재 여부를 확인합니다. 아직 공개되지 않은 주소에는 다운로드 링크를 만들지 않습니다. 새 게임을 추가하려면 JSON에 항목을 추가한 뒤 스크립트를 실행합니다. 자동 예약 갱신은 설정하지 않았습니다.

## 배포

GitHub Pages에서 배포 브랜치의 루트를 게시합니다. `index.html`, `assets/`, `data/`, `.nojekyll`을 함께 유지합니다. 모든 내부 경로는 상대 경로여서 계정 루트와 프로젝트 Pages 주소에서 모두 동작합니다.

검사 후 `git push origin main`으로 배포합니다. 이전 프로젝트 주소는 새 루트 주소로 이동하도록 안내합니다.

원본 게임·BIOS·패치 완료 게임 파일·인증정보는 사이트에 포함하지 않습니다. 장식 그래픽은 사이트용 타이포그래피이며 게임 실행 화면이 아닙니다.

## 작은 게임방 디자인과 이미지

따뜻한 조명, CRT TV, 두 개의 유선 패드와 게임장 카드로 어린 시절 친구들과 게임하던 분위기를 표현했습니다. 캐치프레이즈는 **그때 그 방의 추억을, 우리말로 다시.** 입니다.

현재 16개 항목에 이미지가 있으며 실제 게임 캡처·그래픽 작업 이미지·영상 자막을 구분합니다. 한글 타이틀을 우선 사용하고 이미지 클릭 시 상세창에 표시합니다. 확인되지 않은 3개 항목은 캡처 준비 중입니다. [이미지 출처](docs/SCREENSHOT_SOURCES.md)를 확인하세요. 원본 PNG 또는 동일 픽셀의 무손실 WebP를 사용합니다.

2026-10-16 어나더 코드·쉬버스·라쿠가키 쇼타임·프리니는 사용자가 제공한 타이틀 전체 화면으로 교체했습니다. 데스 주니어도 기존 PPSSPP 타이틀 캡처를 찾아 교체하여 현재 이미지 16개는 모두 게임 캡처입니다. 새 첨부와 타이틀 PNG는 자르거나 보정하지 않았습니다. 각 이미지의 촬영 버전과 설명은 출처 문서를 따릅니다.

`data/screenshots.json`이 이미지 원장이며 목록 갱신 스크립트가 이를 보존합니다. `scripts/import_screenshots.py`는 원래 작업 공간의 캡처가 있는 경우에만 재현할 수 있습니다. 사이트 구동에는 Python/Pillow가 필요하지 않습니다.
