# AKUMA815 한글 패치 아카이브

**사이트: https://akuma815.github.io/**

게임과 독립된 `akuma815/akuma815.github.io` 저장소의 `main` 브랜치를 GitHub Actions로 검사·게시합니다. [최신 인계](docs/HANDOFF.md)

게임별 한글 패치·최종 릴리즈·적용 안내를 모은 GitHub Pages 정적 사이트입니다.

## 기능

- 한국어·영문 게임명 검색, 플랫폼 필터, 정렬, 배포 중인 패치만 보기
- 게임별 상세 안내와 공개 릴리즈·소스 링크
- 공개 등록 대기와 배포 중 상태 구분
- 모바일 레이아웃, 키보드 탐색, 상세 대화상자
- 접속·새로고침할 때마다 모니터 안에 무작위 게임 캡처 표시
- 플랫폼별 팩·케이스 모양의 게임 목록과 한글 타이틀 화면 라벨
- 팩 선택 → 게임기에 꽂기 → CRT 화면 스타일의 게임 소개. 바로 열기·Esc 닫기·키보드 선택·움직임 줄이기 지원
- 게임별 담벼락 방명록과 버그 칠판. 사이트에서 초안 작성 후 GitHub에서 최종 등록하고, 다른 방문자의 글도 함께 읽기

## 로컬 미리보기

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 빌드 및 npm 설치가 필요 없습니다.

기본 정적·DOM 검사는 `python scripts/check_site.py`로 실행합니다. 팩 선택·삽입·소개 전환을 실제 독립 브라우저에서 검사하려면 서버를 켠 상태에서 다음을 실행합니다. QA PNG와 결과 JSON은 Git에서 제외되는 `qa/cartridges/`에 저장합니다.

```powershell
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
python scripts/check_cartridges_browser.py
```

이미 설치된 Microsoft Edge로 검사할 때는 브라우저 설치 명령 대신 `python scripts/check_cartridges_browser.py --channel msedge`를 사용합니다. 이 검사는 사용자 브라우저 프로필과 분리된 헤드리스 테스트 브라우저를 사용합니다. 예약 배포는 기존의 가벼운 정적·DOM 검사를 계속 사용합니다.

방명록·신고의 운영 방식, 새 게임 연결과 브라우저 검사 방법은 [담벼락과 칠판 안내](docs/COMMUNITY.md)를 따릅니다. 글은 각 게임 GitHub 저장소의 Issues에 공개로 저장합니다. 별도 서버나 사이트 내 토큰 없이 읽고, 작성은 방문자가 GitHub 계정으로 최종 등록합니다.

## 목록 갱신

`data/catalog.json`이 목록 원장입니다. `data/catalog.js`는 같은 내용을 브라우저에서 읽을 수 있도록 생성한 파일입니다.

```powershell
python scripts/update_catalog.py --verify-remote
```

로그인된 GitHub CLI로 공개 저장소와 릴리즈 첨부 존재 여부를 확인합니다. 아직 공개되지 않은 주소에는 다운로드 링크를 만들지 않습니다. 새 게임을 추가하려면 JSON에 항목을 추가한 뒤 스크립트를 실행합니다.

`.github/workflows/catalog-pages.yml`이 매시간 17분(UTC, 한국도 매시 17분), main 푸시, 수동 실행 시 공개 릴리즈를 확인하고 검사 후 사이트를 배포합니다. GitHub 예약 실행은 지연되거나 비활성 저장소에서 중지될 수 있으므로 즉시 반영하려면 Actions에서 **Run workflow**를 실행하세요. 기존 등록 게임의 버전·릴리즈 링크·공개 상태만 자동 갱신하며, 번역 범위 설명과 캡처는 직접 관리합니다. 첨부가 있는 공개 릴리즈를 GitHub API 반환 순서대로 선택하므로 사전 배포본도 선택될 수 있습니다.

## 배포

GitHub Pages의 게시 소스는 **GitHub Actions**입니다. 워크플로가 `index.html`, `assets/`, `data/`, `.nojekyll`만 묶어 게시합니다. 모든 내부 경로는 상대 경로여서 계정 루트와 프로젝트 Pages 주소에서 모두 동작합니다.

`git push origin main`으로 검사·배포가 시작됩니다. 자동 목록 커밋은 별도 빌드를 유발하지 않으므로 동일 워크플로가 Pages 아티팩트 배포까지 수행합니다. 이전 프로젝트 주소는 새 루트 주소로 이동하도록 안내합니다.

원본 게임·BIOS·패치 완료 게임 파일·인증정보는 사이트에 포함하지 않습니다. 장식 그래픽은 사이트용 타이포그래피이며 게임 실행 화면이 아닙니다.

## 작은 게임방 디자인과 이미지

사이트 한글은 어린이 손글씨 느낌의 **개구(Gaegu)**를 사용합니다. 제목과 본문 크기·줄 간격을 조정했고 Regular/Bold WOFF2를 사이트에 동봉했습니다. [폰트 출처와 라이선스](docs/FONTS.md)

따뜻한 조명, CRT TV, 두 개의 유선 패드와 게임장 카드로 어린 시절 친구들과 게임하던 분위기를 표현했습니다. 캐치프레이즈는 **그때 그 게임, 기억나? 우리말로 다시 놀자!** 입니다. 메인 소개·검색 안내·게임 21개의 소개와 상세 안내는 어린아이가 친구에게 이야기하는 친근한 반말로 통일했습니다. 적용 조건과 검증 범위는 정확하게 유지합니다.

공개된 21개 게임 모두 실제 게임 전체 화면 이미지가 있습니다. 타이틀 19개와 Switch 이식판 게임 소개·한글 메뉴 2개로 구분합니다. 이미지를 팩 라벨로 표시하며 팩을 고르면 같은 라벨의 팩이 게임기에 꽂히고 상세창의 CRT 화면에 전체 캡처가 나타납니다. 팩·게임기는 CSS로 그렸으며 이미지 원본은 변경하지 않았습니다. 플랫폼에 따라 패미컴/GBA/DS/Switch 팩, PS1/PC Engine 케이스, PSP UMD, PC 상자, 아케이드 기판을 모티프로 표현합니다. [이미지 출처](docs/SCREENSHOT_SOURCES.md)를 확인하세요. 원본 PNG 또는 동일 픽셀의 무손실 WebP를 사용합니다.

닌자군 - 마성의 모험 v1.0은 타이틀 로고만 번역한 정식 릴리즈입니다. 배포 결과 ROM과 동일한 SHA-256의 Mesen 실제 타이틀 PNG를 그대로 연결했습니다. 새 항목도 매시간 릴리즈 확인 대상에 포함됩니다.

2026-10-16 어나더 코드·쉬버스·라쿠가키 쇼타임·프리니·다크 실 1·2·Switch 천사의 시 1·2에 사용자 촬영 화면을 반영했습니다. 데스 주니어도 기존 PPSSPP 타이틀 캡처로 교체했습니다. 새 PNG는 자르거나 보정하지 않았습니다. 각 이미지의 촬영 버전과 설명은 출처 문서를 따릅니다.

`data/screenshots.json`이 이미지 원장이며 목록 갱신 스크립트가 이를 보존합니다. `scripts/import_screenshots.py`는 원래 작업 공간의 캡처가 있는 경우에만 재현할 수 있습니다. 사이트 구동에는 Python/Pillow가 필요하지 않습니다.

톰과 제리 v1.0은 일본판 NES 타이틀 두 부분과 도입부·엔딩 일본어 18행을 한글화한 정식 릴리즈입니다. 배포 결과와 같은 ROM의 실제 타이틀을 연결했습니다. 엔딩 표시는 진단 실행으로 확인했으며 정상 플레이 엔딩 도달·전체 플레이는 미검증입니다.
